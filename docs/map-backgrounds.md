# 맵 배경 시차와 자동 스크롤

발판 전경은 기존 맵 카메라로 이동하고, 배경은 화면 크기의 별도 Canvas에 그립니다.
`front`와 레이어 인덱스 순서를 유지하고, WZ의 `rx`, `ry`, `cx`, `cy`를 API·로컬
manifest·영속 캐시에 보존합니다. 이전 캐시에는 이 값이 없어 캐시 버전을 2로 올렸습니다.

- 일반 축: 비율 0은 화면 고정, -100은 발판과 같은 속도, -50은 절반 속도입니다.
- 타입 4·6은 가로 자동 이동, 5·7은 세로 자동 이동입니다. 해당 축은 비율 값 × 5px/초로 흐릅니다.
- 반복 간격은 `cx`, `cy`를 사용하며 0이면 그림 크기를 사용합니다. 그림은 늘리지 않고
  원본 크기로 그리므로, 큰 간격은 빈 공간을 남기고 작은 간격은 그림이 겹칩니다.
- 좌우 반전은 그림과 origin에만 적용하고 카메라 이동 방향은 유지합니다.
- 높이 600px를 넘는 화면은 기존 배경 조합을 화면 하단에 맞춥니다. 화면 중앙을
  그대로 기준 삼으면 서로 다른 시차 비율 때문에 산·구름 띠의 아래 끝이 벌어집니다.
  하단 기준점을 카메라 세계 좌표 계산에도 함께 적용해 발판과 같은 깊이(-100)의
  레이어 및 자동 이동 레이어는 기존 맵 좌표를 유지합니다. 이미지를 확대하거나
  경계를 흐리게 처리하지 않습니다.
- 정적인 배경은 카메라·레이아웃·이미지가 바뀔 때만 다시 그립니다. 자동 이동은
  숨겨진 탭과 `prefers-reduced-motion`에서 멈춥니다.

속성 해석은 [WzComparerR2의 GetMeshBack](https://github.com/Kagamia/WzComparerR2/blob/master/WzComparerR2.MapRender/FrmMapRender2.SceneRendering.cs#L798)과
[BackItem](https://github.com/Kagamia/WzComparerR2/blob/master/WzComparerR2.MapRender/Patches2/BackItem.cs)을 대조했습니다.
공식 클라이언트와의 프레임 단위 일치 검증은 하지 않았습니다. 배경 그림 자체는 기존처럼
첫 프레임을 사용하며, 이번 변경은 카메라 시차·반복 간격·자동 이동을 처리합니다.

KMS 389 구름공원1(200010000) 원본 확인 예:

| 레이어 | 타입 | rx | ry | cx | 동작 |
| --- | --- | --- | --- | --- | --- |
| 0 | 3 | 0 | 0 | 0 | 화면에 고정된 하늘 |
| 1 | 1 | 0 | -5 | 0 | 가로 고정, 세로 5% 시차 |
| 11 | 4 | 7 | -17 | 700 | 가로 35px/초 이동, 세로 17% 시차 |
| 13 | 1 | -35 | -50 | 500 | 가로 35%, 세로 50% 시차 |

구름공원1은 동작 확인용으로 원본 복원을 검증했습니다. 사용자가 아직 배치 좌표를 지정하지
않았으므로 로컬 맵 목록에는 추가하지 않았습니다.

큰 화면의 하단 경계 보정은 이 앱의 반응형 배치 규칙입니다. 600px 이하의 중앙 기준과
600px보다 큰 화면의 하단 기준을 사용합니다. 구름공원1의 실제 원본 이미지로 기존의
가로 끊김을 재현하고, 동일한 카메라 깊이에서 보정 후의 정적 합성을 확인했습니다.
이는 브라우저 조작 및 공식 게임 전체 카메라 범위의 동작 검증을 대신하지 않습니다.

## 맵을 고른 뒤 원본 복원

로컬 보관 맵 외에는 `reconstructMap`이 선택한 맵의 원본을 복원합니다.
`wzImgMetadata`는 원본 IMG 속성을 읽고, `mapSourcePlan`은 타일·오브젝트·배경의
첫 프레임과 UOL/inlink/outlink를 해석합니다. `mapSourceClient`는 중복 요청을 합치고,
동시 요청을 6개로 제한하며, 일시적인 네트워크/서버 오류를 한 번 재시도합니다.

모든 그림이 준비되면 전경을 원본 miniMap 캔버스 크기에 합성하고, 배경은 개별 Blob으로
유지해 시차 렌더러에 전달합니다. API `/map/{id}/render`에는 의존하지 않습니다.
완성된 Blob과 배경 메타데이터만 별도 키로 IndexedDB에 저장합니다. 실패·취소 결과는
완성 캐시에 넣지 않으며, 맵을 바꾸면 진행 중 요청과 Blob URL을 정리합니다.

좌표 복사 JSON은 지역·버전과 원본 캔버스 크기를 포함합니다. 배포용 생성기도 같은
원본 캔버스를 사용하고 복사한 크기와 비교합니다. 브라우저에서 복원한 맵이 자동으로
프로젝트의 배포 목록에 추가되지는 않습니다.

현재 검증 범위는 일반 래스터 타일·오브젝트·배경입니다. 회전 오브젝트, Spine 등
지원하지 않는 특수 형식은 누락된 화면을 완료로 표시하지 않고 복원 오류를 냅니다.
움직이는 오브젝트와 그림 자체의 애니메이션은 첫 프레임 스냅샷입니다.
