# GA4 이벤트 설계

사용자의 행동은 적은 수의 한국어 이벤트로 구분하고, 몬스터·데미지 스킨·설정의 상세 내용은 매개변수로 분석한다.

| 이벤트 이름        | 수집 시점                              | 주요 분석 내용                                                    |
| ------------------ | -------------------------------------- | ----------------------------------------------------------------- |
| `선택창_열기`      | 몬스터 또는 데미지 스킨 선택창을 열 때 | 선택 대상, 현재 선택값                                            |
| `몬스터_선택`      | 몬스터 선택이 적용될 때                | 이름, ID, 레벨, 보스 여부, 이전 몬스터, 검색 사용 여부            |
| `데미지_스킨_선택` | 데미지 스킨이 적용될 때                | 이름, 아이템/이펙트 ID, 일반·유닛·액션 유형, 필터, 검색 사용 여부 |
| `데미지_설정_변경` | 변경한 설정창을 닫을 때                | 변경 항목, 최소·최대 데미지, 크리티컬 확률, 공격 타수             |
| `몬스터_공격`      | 몬스터를 클릭해 데미지를 표시할 때     | 몬스터, 스킨, 데미지 설정, WZ 버전                                |
| `표시_언어_노출`   | 앱 진입 및 표시 언어가 바뀔 때         | 실제 표시 언어, 자동·직접 선택 여부                               |
| `표시_언어_변경`   | 설정에서 표시 언어를 직접 바꿀 때      | 이전·다음 언어, 자동·직접 선택 여부                               |

`page_view`, `session_start`, `scroll` 등은 GA4가 자동으로 수집하는 예약 이벤트라 이름을 변경하지 않는다. 이전에 수집된 `Attack_mushroom`, `Select_skin` 등도 소급해 이름이 바뀌지 않으며, 배포 후부터 새 이벤트로 수집된다.

## GA4 관리자 설정

코드가 보낸 매개변수를 탐색 및 리포트에서 사용하려면 **관리 > 데이터 표시 > 맞춤 정의**에 등록한다.

권장 이벤트 범위 맞춤 측정기준:

| 표시 이름           | 이벤트 매개변수     |
| ------------------- | ------------------- |
| 선택 대상           | `selection_type`    |
| 몬스터 이름         | `monster_name`      |
| 몬스터 구분         | `monster_category`  |
| 데미지 스킨 이름    | `skin_name`         |
| 데미지 스킨 유형    | `skin_type`         |
| 선택 당시 스킨 필터 | `skin_filter`       |
| 변경한 설정         | `changed_fields`    |
| 실제 표시 언어      | `ui_locale`         |
| 언어 선택 방식      | `locale_preference` |

권장 이벤트 범위 맞춤 측정항목:

| 표시 이름     | 이벤트 매개변수      | 단위 |
| ------------- | -------------------- | ---- |
| 몬스터 레벨   | `monster_level`      | 표준 |
| 스킨 변형 수  | `skin_variant_count` | 표준 |
| 최소 데미지   | `minimum_damage`     | 표준 |
| 최대 데미지   | `maximum_damage`     | 표준 |
| 크리티컬 확률 | `critical_rate`      | 표준 |
| 공격 타수     | `attack_count`       | 표준 |

각종 ID는 고카디널리티를 피하기 위해 기본 맞춤 측정기준으로 등록하지 않는다. 사용자가 입력한 원문 검색어는 개인정보 및 고카디널리티 위험을 피하려고 수집하지 않는다.

`ui_locale`과 `locale_preference`는 위 두 언어 이벤트뿐 아니라 모든 맞춤 이벤트에 공통으로 붙는다. 국가별 방문은 GA4 기본 국가 측정기준으로, 실제 사용 언어는 `ui_locale`로 교차 분석한다.

## 환경 변수와 검증

- 배포: `VITE_GA_MEASUREMENT_ID=G-...` 값이 있을 때만 수집한다.
- 로컬 개발: 기본적으로 수집하지 않아 운영 데이터 오염을 막는다.
- 로컬 DebugView: `VITE_GA_DEBUG=true` 일 때만 수집하며 `debug_mode` 설정을 적용한다.

배포 후 GA4 **DebugView** 또는 **실시간 > 이벤트 수**에서 새 한국어 이벤트와 매개변수를 확인한다.
